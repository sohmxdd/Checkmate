# Security Policy

## Supported Versions

Only the latest release and the current main branch receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |

## Reporting a Vulnerability

If you discover a potential vulnerability within CHECKMATE:

1. Do not open a public issue.
2. Email the maintainer or report via private GitHub vulnerability reporting.
3. Include reproduction steps, environment details, and affected components.

Security reports will be acknowledged within 48 hours.
