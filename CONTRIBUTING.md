# Contributing to CHECKMATE

Thank you for your interest in contributing to CHECKMATE.

## Development Workflow

1. Fork the repository and create a feature branch from main.
2. Set up a local Python virtual environment:
   python -m venv .venv
3. Install dependencies:
   pip install -r requirements.txt
4. Ensure your changes follow clean, testable design principles.
5. Submit a pull request describing the rationale and changes made.

## Code Standards

- Write clean, type-annotated Python code (PEP 8).
- Do not commit keys, secrets, or encrypted test artifacts.
- Keep documentation up to date with new features.
